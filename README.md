# Jaypalsinh Bhati — Personal Portfolio

A simple, minimal personal portfolio website built as a B.Tech CSE Semester 3 college assignment using plain HTML, CSS, and JavaScript.

## Features

- Vintage-modern editorial layout with warm neutral tones and dark mode toggle
- Responsive navigation bar with a mobile hamburger menu
- About, Skills, Projects, and Contact sections
- Interactive preview for the Registration Form and Colour Changer & Live Text projects
- Subtle scroll-reveal animations and hover transitions
- Client-side contact form validation

## Technologies

- HTML5 (semantic structure)
- CSS3 (CSS variables, Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, `addEventListener`, `IntersectionObserver`)
